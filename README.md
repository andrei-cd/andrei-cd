## Featured projects

### 🖊️ [AirCursor](https://aircursor.app): iPad + Apple Pencil as a Mac drawing tablet and trackpad

Native Swift app for iPadOS and macOS, currently in TestFlight ahead of App Store release.

- **<3 ms** wired round-trip latency
- Multiple transports (TCP, encrypted UDP, Bluetooth LE L2CAP) with automatic fallback and reconnect
- Code-based pairing (CPace/X25519) with brute-force lockouts; every frame encrypted with ChaChaPoly
- Pressure, tilt, and hover streamed as compact binary packets, with jitter smoothing
- ~17K lines of Swift, **200+** unit and loopback integration tests

`Swift` `SwiftUI` `Network.framework` `CryptoKit` `CoreGraphics`

### 🏗️ [Build a Bunker](https://www.roblox.com/games/116626307286529/Build-a-Bunker): live-service Roblox tycoon

Sole programmer and UI engineer for a cross-platform game (desktop, mobile, console).

- **200K+ visits**, **2K peak DAU**, **200 peak CCU**, **$600+ revenue**
- Top 10% for monetization and top 25% for playtime at peak
- Re-architected the live game from Studio-only scripts into a modular **55K-line** Rojo/Luau codebase with typed client-server services and automated type checking
- Server-authoritative room placement and BFS pathfinding for NPCs through player-built layouts
- Versioned lazy migration over a **125K-key** production data store, preserving returning players' data

`Luau` `React Lua` `Rojo` `luau-lsp`

### 📦 [MyBalikBox](https://github.com/robbie2005/mybalikbox): 🏆 Best Overall ICS Project, FUSIONCon 2026

Mobile app that helps families plan Balikbayan boxes together. I led the 7-engineer team through Scrum and built the Discover social feed: PostgreSQL schema, 10+ row-level security policies, and image storage.

`TypeScript` `React Native` `Expo` `Supabase` `PostgreSQL`
